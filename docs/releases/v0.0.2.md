# v0.0.2

本次发布把 SerialMateX 的 TASK 自动化测试补成一套能真正跑老化测试的工具：电源指令走设备自己的串口、每轮可做 PING 连通性检查、任务结束写统计总结，另外修掉了界面上一批实际用起来会硌手的地方。

## 新增

- **PING 检测**：AUTO CMD 列表下方新增 PING 行（目标地址 + 开关）。开启后每轮命令跑完先 ping 目标地址 4 包，丢包率 ≤50% 算通过；不通过时若开了「异常暂停」就停在该状态等人工决定，否则记一次异常并继续下一轮。首次使用时地址为空或格式不对会直接提示，不会悄悄存下去。
- **任务总结**：任务结束后日志末尾追加统计块——总测试轮数、命令执行、PING 检测各自的正常 / 异常 / 总数，以及失败轮次的明细（第几轮、是哪条命令没等到匹配数据、还是 PING 丢包率多少）。
- **命令未完成时说明原因**：以前只看到「正常次数比总轮次少一轮」，现在日志里会有 `[CMD …] 第 N 次测试未完成：…`，指出是超时、没轮到、发送失败还是延时吃满。
- **电源指令走设备串口**：TASK 里选择的电源设备现在用自己的 COM 口（波特率 / 数据位 / 停止位 / 校验位可配），不再借用 SERIAL 那条连被测板的通道。
- **AUTO CMD 支持 HEX 与回车控制**：每条命令可单独选「是否 HEX」「是否带回车」，行尾数字改称「延时」；设备的上电/掉电指令同样有这两个开关。
- **异常暂停时可选择去向**：暂停后右下角给出「结束任务」与「跳过本轮」——前者掉电并结束整轮任务，后者不计正常次数、掉电后按间隔时间开下一轮。
- **RX MONITOR 行视图**：接收区按行显示，任务发出的命令以绿色 `[TX]` 行标出，功能键显示成 `{UP}` / `{ENTER}` 而不是不可见字节。

## 改进

- 左栏底部的「编辑设备参数」按钮文字居中。
- SERIAL 波特率改成 4800–921600 的典型值下拉，Plot 标签置灰标注「暂未开放」。
- 窗口底色跟随上次选择的皮肤，启动不再闪一下深色底。
- exe 恢复应用图标与版本信息（此前 `go build` 不生成资源，文件属性里没有图标和版本）。

## 修复

- **退格键与功能键**：接收区聚焦后 Backspace、Delete、方向键、Home/End、PageUp/PageDown、Esc、Ctrl+字母都能正确发送对应字节或转义序列；设备回显的 `\b` 与 `\r` 也能正确删字符、覆盖本行（进度条式刷新不再糊成一行）。
- **输入时标题下方多出一根线**：日志区键入时命中了全局焦点环，2px 描边被面板裁得只剩顶边；已单独关掉接收区的焦点环。
- **AUTO CMD 启动后仍高亮着上次选中的命令**：启动成功后自动清除选中。
- **暂停态提示**：暂停时顶部徽标改为 `PAUSED`，提示行读后端消息，决策按钮防连点。

## 使用提示

- 附件里的 `SerialMateX.exe` 是便携版，双击即用；配置与日志写在 exe 同目录（`pwr_dev.ini`、`auto_cmd.txt`、`task_config.ini`、`ui_config.ini`）。
- 若双击后窗口打不开，通常是安全软件拦截了 `WebView2` 的控制器进程：把 exe 所在目录加入信任区，或换个普通目录（不要放在带「拒绝删除」ACL 的项目目录里）再运行。
- 应用内「检查更新」已指向本仓库，需要本 release 上传名为 `SerialMateX.exe` 的附件才能自动更新。
- 本轮 34 个提交、35 个变更文件；`go test ./...` 三个包全绿，前端 `npm run build` 通过。
